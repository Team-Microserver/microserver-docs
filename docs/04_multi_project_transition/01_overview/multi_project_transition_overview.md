# 멀티 프로젝트 전환 개요

> **상태: 작성 예정**

단일 Spring Boot 프로젝트를 MicroServer Framework 구조로 전환하는 단계와 Repository 경계를 설명한다.

## 문서 목적

이 문서는 전체 MicroServer 구축 Lifecycle에서 해당 단계의 위치를 먼저 확보하여 MkDocs NAV 링크 오류가 발생하지 않도록 생성한 기본 가이드 문서다.

## 작성 예정 범위

- 상세 설계 기준
- 구성 절차
- 검증 방법
- 운영 시 주의사항
- 예제 및 Troubleshooting

!!! note "작성 원칙"
    실제 구현 및 검증이 진행되는 시점에 소스 코드와 실행 결과를 기준으로 내용을 구체화한다.
