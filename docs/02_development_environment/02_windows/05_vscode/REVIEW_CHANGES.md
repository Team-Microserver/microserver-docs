# VS Code 가이드 재구성 반영사항

- `vscode_global_settings.md`를 `vscode_portable_setup.md`로 변경
- 문서 제목을 `Windows VS Code Portable 설정`으로 변경
- Portable 설정 문서에서 JDK Runtime / settings.json 상세 구성 제거
- User Settings 상세 구성은 `vscode_user_settings.md`로 집중
- Java Extension 문서의 JDK Runtime JSON 중복 제거 후 User Settings 문서 연결
- VS Code 설치 문서의 다음 단계 링크를 Portable 설정으로 수정
- JDK 연계 문서의 legacy 통합 문서 링크를 현재 문서 흐름으로 변경
- `vscode_setup.md` 제목 및 전체 진행 순서를 새 NAV에 맞게 수정
- legacy 통합 문서는 보존하되 NAV에서는 제외
