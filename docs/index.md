# Microserver

금융 SI 프로젝트에서 반복적으로 필요한 공통 기능과 시스템 연계 구조를 표준화하고,
실제 프로젝트에서 재사용할 수 있는 **금융 SI 표준 Framework / Reference Architecture**를
직접 구축하는 프로젝트입니다.

이번 프로젝트는 완성된 프레임워크를 설명하는 방식이 아니라,
**빈 프로젝트에서 시작하여 기능을 하나씩 구현하고, 문서화하고, Git Commit & Push 하는 과정 자체를 기술 자산으로 축적**하는 방식으로 진행합니다.

## 진행 원칙

1. 프로젝트를 처음부터 단계적으로 구축합니다.
2. 각 단계마다 실제 실행과 테스트를 수행합니다.
3. 구현 내용과 설정 방법을 Markdown 문서로 남깁니다.
4. 완료된 단계는 Git Commit & Push 합니다.
5. 기존 MicroServer 자료는 참고하되 현재 기술 스택과 VS Code 환경에 맞게 재구성합니다.
6. macOS와 Windows에서 동일한 Git 저장소를 사용하되, 로컬 가상환경은 각 PC에서 별도로 구성합니다.

## 문서 구성

- Home
- 프로젝트 시작
- Framework 구축
- 업무 및 금융 연계
- 확장 아키텍처
- 참고자료

> 현재 기본 문서 구조를 구성하고 있으며, 세부 기술 문서는 실제 구축 순서에 맞춰 단계적으로 작성합니다.
