# 💡 MicroServer 프레임워크

## 🎯 금융 SI 프로젝트를 효율적으로 수행하기 위한 표준 개발 프레임워크

MicroServer는 금융 SI 프로젝트에서 반복적으로 필요한 개발 환경, 공통 기능,
전문 연계, 보안 및 운영 기능을 표준화하여 제공하는 Spring Boot 기반 프레임워크입니다.

> 이 문서는 MicroServer를 처음부터 다시 구축하면서 각 단계의 설계, 구현,
> 검증 및 운영 방법을 함께 정리하기 위한 가이드입니다.

## 현재 상태

MkDocs 기본 환경을 구성하고 전체 문서 구조를 설계하는 단계입니다.
