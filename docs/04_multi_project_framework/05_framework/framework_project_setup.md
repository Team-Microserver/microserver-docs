# Framework 프로젝트 구성

## 문서 목적

Runtime 업무 개발에 필요한 공통 기술 기반을 제공하는 MicroServer Framework 프로젝트를 구성합니다.

## 기본 방향

Framework는 단순 Utility 모음이 아니라 Runtime 개발자가 기술 기반 설정보다 업무 구현에 집중할 수 있도록 표준 설정과 기본 동작을 제공하는 것을 목표로 합니다.

## 검토 대상

- Configuration
- DataSource / Transaction
- Web 공통 처리
- Exception / Standard Response
- Validation
- Logging
- Security
- Cache
- 전문 처리
- 공통 Utility

위 항목은 후보이며 실제 포함 범위와 프로젝트 분리 여부는 기능 구현 과정에서 확정합니다.

> 문서 상태: **설계 진행중**
