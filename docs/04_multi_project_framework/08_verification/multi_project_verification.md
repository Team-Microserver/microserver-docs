# 멀티프로젝트 Framework 검증

## 문서 목적

구성된 MicroServer Framework, Runtime, Admin의 Build 및 실행 구조가 설계 의도대로 동작하는지 검증합니다.

## 검증 예정 항목

- Root 전체 Build
- Framework Library Build
- Runtime 단독 실행
- Admin 단독 실행
- Runtime의 Framework Dependency 확인
- 프로젝트 간 금지 의존성 확인
- Resource 및 Configuration 로딩 확인
- 테스트 실행

세부 검증 명령과 기대 결과는 실제 프로젝트 구성 이후 작성합니다.
