# Runtime Application 구성

## 문서 목적

MicroServer Framework를 사용하는 실제 Runtime Application의 기본 구조와 구성 방법을 정의합니다.

## 기본 방향

Runtime은 프로젝트에 따라 Banking, 일반 Web Application, API Server 등 다양한 형태가 될 수 있습니다. Framework 내부 구현을 최소한으로 의식하면서 Controller, Service, Domain, Repository/Mapper 등 실제 업무 개발에 집중할 수 있는 구조를 목표로 합니다.

## 작성 예정 내용

- Runtime 실행 구조
- Framework Dependency 적용
- 업무 Package 구성
- Runtime 전용 Configuration
- Resource 구성
- Sample 업무 기능 구현
- 실행 및 테스트
